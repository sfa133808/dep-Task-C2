# C2 - CI/CD mit GitHub Actions

Dieses Repository ist bewusst zuerst nur als Scaffold angelegt. Ziel dieses ersten Commits ist eine saubere Grundstruktur fuer die spaetere Umsetzung der GitHub-Actions-Pipeline.

## Aktuelle Struktur

- [src/](src/) fuer die spaetere Anwendung
- [test/](test/) fuer automatisierte Tests
- [.github/workflows/](.github/workflows/) fuer den CI/CD-Workflow
- [Dockerfile](Dockerfile) als Platzhalter fuer das Container-Image

## Naechster Ausbauschritt

In einem zweiten Schritt werden dann Build, Test, Push, Tagging und die Dokumentation der Entscheidungen konkret umgesetzt.
